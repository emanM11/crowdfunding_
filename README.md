# Crowdfunding Platform

منصة تمويل جماعي (Crowdfunding) بمعمارية منفصلة: باك إند Django REST
Framework + فرونت إند React. راجع `PROJECT_SPEC.md` للتفاصيل الكاملة —
هو المرجع الرسمي والملزم لكل قرارات الموديلز والـ API.

## الهيكل

```
backend/    -> Django + DRF (API فقط، بدون templates)
frontend/   -> React (Vite) بيستهلك الـ API
```

## تشغيل الباك إند

```bash
cd backend
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # واملأ بيانات الاتصال بقاعدة البيانات فيه
# اعمل قاعدة بيانات PostgreSQL بنفس الاسم اللي حطيته في .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

الباك إند هيشتغل على `http://127.0.0.1:8000/`.

## تشغيل الفرونت إند

```bash
cd frontend
npm install
cp .env.example .env            # عدّل VITE_API_BASE_URL لو الباك إند شغال على بورت مختلف
npm run dev
```

الفرونت إند هيشتغل على `http://localhost:5173/`.

## مراجعة شاملة نهائية مقابل PROJECT_SPEC.md (بند ببند)

راجعت المشروع كامل مقابل كل بند في السبيك (الموديلز، الـ API contract،
الصلاحيات، الأمان، الأداء، الأدمن). النتيجة:

**بجات حقيقية اتلقطت واتصلحت في المراجعة دي:**
- أدمن Django كان بيعرض حقل `status` الخام بس (يعني مشروع فات معاد
  انتهائه كان لسه شكله "running" في قايمة الأدمن). دلوقتي بيعرض
  `computed_status` الحقيقي (يشمل "ended"). اتأكدت منها بصريًا بعد الإصلاح.
- الردود على التعليقات (bonus) ما كانش ليها زرار "إبلاغ" مستقل — كنت بس
  قادر تبلّغ عن التعليق الأساسي. اتضافت، واتأكدت إن البلاغ بيتسجّل على
  الرد نفسه (comment ID الصحيح) مش على التعليق الأب.

**اتأكدت فعليًا (مش افتراض) من:**
- كل التواريخ/الأوقات في الكود بتستخدم `timezone.now()`/`timezone.localdate()`
  — مفيش أي `datetime.now()` غير واعي بالـ timezone في أي مكان.
- انتهاء صلاحية توكن التفعيل (24 ساعة) وتوكن استعادة كلمة السر (ساعة):
  اختبرت الحدود فعليًا (23h/25h و59min/61min) عبر الـ endpoint الحقيقي.
- قاعدة الإلغاء عند 25% بالظبط (لازم ترفض، مش تقبل) — متأكد منها.
- الـ `/api/projects/` **عمدًا** مبيدعمش `?category=<slug>` كـ query param
  (فيه ملاحظة صريحة في السبيك بترجّح ده على الإشارة الأولى ليه في نفس
  الملف) — التصفية بالفئة بس عن طريق `/api/categories/<slug>/projects/`.

**قرار تصميمي واضحلك محتاج تعرفه (مش باج، بس اختلاف عن المثال التوضيحي
في السبيك):**
السبيك في قسم 6.1 بيوضّح شكل الـ response بمثال `tags: ["health","kids"]`
و `images: ["url1","url2"]` (مصفوفة نصوص/روابط بسيطة). أنا بنيت `tags`
و`images` كمصفوفة كائنات (`{id, name}` و`{id, image}`) بدل النص الخالص،
لأن الفرونت إند محتاج الـ `id` (لعرض الصور الحالية في صفحة التعديل، وكـ
React key مستقر). السبيك نفسه بيقول "أسماء الحقول متتغيرش، بس القوائم
ممكن تتوسّع" — اعتبرتها توسيع مش تغيير اسم. الاتنين (باك إند وفرونت إند)
متطابقين ومُختبرين end-to-end، بس حابب أكون واضح إن ده قرار مني مش نسخ
حرفي من المثال، لو حابب ترجعه للشكل البسيط قولّي.
